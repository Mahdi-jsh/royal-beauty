## ✨ ویژگی‌ها

### 🛒 قابلیت‌های فروشگاه
- ✅ سبد خرید تعاملی (افزودن، حذف، تغییر تعداد)
- ✅ ذخیره‌سازی سبد خرید با `LocalStorage`
- ✅ محاسبه خودکار قیمت کل و تخفیف‌ها
- ✅ نمایش محصولات با کارت‌های حرفه‌ای

### 🔍 جستجو و فیلتر
- ✅ جستجوی هوشمند محصولات بر اساس نام
- ✅ فیلتر محصولات بر اساس دسته‌بندی:
  - 💄 آرایشی
  - 🌸 مراقبت پوست
  - 💇 مراقبت مو
  - 🌺 عطر و ادکلن
- ✅ مرتب‌سازی بر اساس قیمت (ارزان‌ترین، گران‌ترین)

### 🎨 طراحی و UI/UX
- ✅ طراحی کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ)
- ✅ رنگ‌بندی اختصاصی لوکس (طلایی و مشکی)
- ✅ انیمیشن‌های نرم و روان
- ✅ سرعت بارگذاری بالا
- ✅ سازگار با تمام مرورگرها

### 💻 قابلیت‌های فنی
- ✅ کد تمیز و قابل توسعه
- ✅ ساختار بهینه HTML برای SEO
- ✅ جداسازی کامل HTML، CSS و JavaScript
- ✅ استفاده از CSS Variables برای مدیریت رنگ‌ها
- ✅ کامنت‌گذاری مناسب در کد
